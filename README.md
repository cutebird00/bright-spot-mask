# Bright Spot Mask · 亮斑遮罩

A Windows utility for adjustable, click-through overlays that reduce the visual distraction of screen bright spots. / 用于减轻屏幕亮斑视觉干扰的 Windows 局部渐变遮罩工具。

| Tool / 工具 | Platform / 平台 | Purpose / 用途 |
| --- | --- | --- |
| [Bright Spot Mask · 亮斑遮罩](bright-spot-mask/) | Windows 10 2004+ / Windows 11 | Adjustable local overlays to reduce the visual distraction of screen bright spots. / 用局部渐变遮罩减轻屏幕亮斑的视觉干扰。 |

## Download / 下载

**[Download from Releases](https://github.com/cutebird00/bright-spot-mask/releases)** — open the latest Bright Spot Mask release and choose `Bright-Spot-Mask-2026.10.07.zip` under **Assets**. Extract it, open the `Bright-Spot-Mask` folder, and double-click `start-mask.cmd`.

**[从 Releases 下载](https://github.com/cutebird00/bright-spot-mask/releases)**：打开最新的 Bright Spot Mask 版本，在 **Assets** 下下载 `Bright-Spot-Mask-2026.10.07.zip`。完整解压后进入 `Bright-Spot-Mask` 文件夹，双击 `start-mask.cmd`。

The app README covers setup, controls, and removal. For the complete repository source, **Code → Download ZIP** remains available. / 具体设置和删除方法见工具目录 README；整个仓库源码仍可通过 **Code → Download ZIP** 下载。
