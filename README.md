# SomeTools

A small collection of practical desktop utilities. / 一些实用的桌面小工具。

| Tool / 工具 | Platform / 平台 | Purpose / 用途 |
| --- | --- | --- |
| [Bright Spot Mask · 亮斑遮罩](bright-spot-mask/) | Windows 10 2004+ / Windows 11 | Adjustable local overlays to reduce the visual distraction of screen bright spots. / 用局部渐变遮罩减轻屏幕亮斑的视觉干扰。 |

Start with the tool's README for setup, controls, and removal instructions.
Download the repository using **Code → Download ZIP**, extract it, and open the `bright-spot-mask` folder.

请先阅读工具目录内的 README。点击 **Code → Download ZIP**，完整解压，再进入 `bright-spot-mask` 文件夹。
